# sitescore-spatial

Deterministic spatial foundation for SiteScore FAZ 3.4 Checkpoint 3.4-1.

This package owns provider-neutral spatial sidecars, CRS/runtime identity, canonical Polygon/MultiPolygon handling, explicit projection/intersection/area operations, and compatibility validation. It intentionally contains no provider acquisition, benchmark frame, metrics, normalization, readiness, scoring, or app logic.

See `docs/CHECKPOINT_3_4_1_SPATIAL_FOUNDATION.md`.
